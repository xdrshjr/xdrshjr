## 🚀 Current project

**[AragonTask](https://github.com/xdrshjr/AragonTODO)** — an offline-first Android app that combines **todos, an expense ledger, and memos** in one calm, paper-textured app, with an optional AI agent powered by *your own* API key.

- ✅ No accounts · no cloud sync · no ads — data never leaves your device
- 🤖 BYO-key AI agent (OpenAI / Anthropic / custom): chat to manage tasks, expenses & memos
- ⚙️ No-Gradle build: aapt2 + javac + d8 + apksigner in a 50-line script
- 🌐 UI in Chinese (zh-CN), English on the roadmap
